# D3 · 数据流水线（精简实操版）

> 本文件是原讲义《D3 数据流水线（上/下）》的精简实操版：**只讲正确做法，去掉试错演绎**。代码为终版，与原讲义最终代码一致，并已在干净环境端到端实测通过。
>
> **与原讲义的一处有意差异**：划分契约（`SampleLineage` / `SplitManifest` / `compute_contract_fingerprint`）放在 `od_platform/common/lineage.py`，而不是原讲义的 `data_pipeline/split/manifest.py`。原因：D4 数据验证子系统要核验这份契约，契约是"跨子系统的公共语言"，必须住在 common 层——D3 生产、D4 核验，两个子系统互不 import。本课相关 import 均已按此写好，照抄即可。

## 0. 本课做什么

一句话：**一条命令，把任意一种标注格式的原始数据集，变成一份"能直接喂给 Ultralytics 训练"的成品数据集，并附一份可被 D4 独立核验的划分契约。**

```
data/raw/demo/                          # 原始数据（只读）
    images/  annotations/  classes.txt
        │
        ▼   odp-transform --dataset demo --format pascal_voc --split-strategy stratified_multilabel
        │
        ├─→ data/processed/demo/                    # 成品数据（可复制、可重建、可整体删除）
        │      images/{train,val,test}/  labels/{train,val,test}/
        ├─→ configs/datasets/demo.yaml              # Ultralytics 配置（含 odp_meta 审计块）
        └─→ runs/data_pipeline/<run_id>/manifest.json   # 划分契约（审计专用，D4 核验它）
```

四条硬规则贯穿全课：

1. **raw 只读**：任何代码不得写 `data/raw/`；
2. **一切走配置**：路径全部来自 `common/paths.py`，不出现硬编码绝对路径；
3. **幂等**：同参数跑两次，成品逐字节一致（`created_at` 等时间戳除外）；想改数据就改参数重跑，不手改 processed；
4. **脏数据绝不进训练目录**：管线对坏数据**直接报错**（exit 1），由人类去修源头；检测脏数据是 D4 质检的语义，两个子系统分工不同。

**前置**：D1（项目骨架）、D2（脚手架）已完成。本课结束时项目内新增：

```
apps/platform/src/od_platform/
├── cli/transform_data.py                 # odp-transform 命令
├── common/
│   ├── lineage.py                        # 划分契约（D3 生产、D4 核验）
```

### 1.1 VOC 演示集（`data/raw/demo/`，63 张）

三个刻意设计：① 12 张图（≈19%）含稀有类 `反光衣`——驱动 D3 的类别平衡报告和分层划分；② `classes.txt` 故意乱序——验证"类名→class_id 由 classes.txt 决定"；③ `c_050.xml` 里埋了一个越界框（xmax=700 > 640）——**留给 D4 质检抓，D3 照常处理**。

```python
# scripts/demo_data/make_demo.py
"""生成 VOC 风格演示数据集 data/raw/demo/(63 张图)。
三个刻意设计:
  1. 12 张图(约19%)含稀有类 反光衣 —— 驱动类别平衡报告和分层划分
  2. classes.txt 故意乱序 —— 类名→class_id 由 classes.txt 决定,不由 xml 出现顺序
  3. c_050.xml 里埋了一个越界框(xmax=700 > 640)—— 留给 D4 质检抓,本课照常处理
幂等:重跑覆盖同名文件。
"""
from od_platform.common.paths import RAW_DATA_DIR

ROOT = RAW_DATA_DIR / "demo"
IMG = ROOT / "images"
ANN = ROOT / "annotations"
IMG.mkdir(parents=True, exist_ok=True)
ANN.mkdir(parents=True, exist_ok=True)

(ROOT / "classes.txt").write_text("反光衣\nhead\n", encoding="utf-8")  # 故意乱序

XML = ("<annotation><size><width>640</width><height>480</height></size>\n"
       "{objs}</annotation>\n")
OBJ = ('  <object><name>{n}</name><bndbox>'
       "<xmin>{a}</xmin><ymin>{b}</ymin><xmax>{c}</xmax><ymax>{d}</ymax>"
       "</bndbox></object>\n")

for i in range(51):
    (IMG / f"c_{i:03d}.jpg").write_bytes(b"")          # 空图:全流程不读像素
    objs = OBJ.format(n="head", a=40 + i % 100, b=60, c=160 + i % 100, d=200)
    (ANN / f"c_{i:03d}.xml").write_text(XML.format(objs=objs), encoding="utf-8")

# 埋雷:c_050 的框故意越界(xmax=700>640),留给 D4 的 bbox_within_image 抓
(ANN / "c_050.xml").write_text(
    XML.format(objs=OBJ.format(n="head", a=500, b=60, c=700, d=200)),
    encoding="utf-8")

for i in range(12):                                     # 稀有类:反光衣
    x = 30 + (i * 11) % 260
    objs = (OBJ.format(n="head", a=40 + i, b=60, c=160 + i, d=200)
            + OBJ.format(n="反光衣", a=x, b=260, c=x + 100, d=420))
    (ANN / f"rare_{i:03d}.xml").write_text(XML.format(objs=objs), encoding="utf-8")
    (IMG / f"rare_{i:03d}.jpg").write_bytes(b"")

print(f"演示数据就绪: {ROOT}  (63 图 / 75 标注, 其中 12 张含稀有类)")
```

### 1.2 COCO 演示集（`data/raw/demococo/`，8 张）

每张图有 bbox（检测）+ segmentation 多边形（分割），前 2 张额外含 `反光衣`，用来演示"同一份原始数据按 task 转出两种标签"。

```python
# scripts/demo_data/make_coco_demo.py
"""生成 COCO 风格演示数据集 data/raw/demococo/(8 张图)。
每张图有 bbox(检测)+ segmentation 多边形(分割),前 2 张额外含稀有类 反光衣。
"""
import json
from od_platform.common.paths import RAW_DATA_DIR

ROOT = RAW_DATA_DIR / "demococo"
IMG = ROOT / "images"
ANN = ROOT / "annotations"
IMG.mkdir(parents=True, exist_ok=True)
ANN.mkdir(parents=True, exist_ok=True)

images, anns = [], []
for i in range(8):
    stem = f"co_{i:03d}"
    (IMG / f"{stem}.jpg").write_bytes(b"")
    images.append({"id": i, "file_name": f"{stem}.jpg", "width": 640, "height": 480})
    anns.append({"id": len(anns), "image_id": i, "category_id": 1,
                 "bbox": [40 + i, 50, 120, 140],
                 "segmentation": [[40 + i, 50, 160 + i, 50, 160 + i, 190, 40 + i, 190]]})
for i in range(2):                                      # co_000, co_001 各加一个 反光衣
    anns.append({"id": len(anns), "image_id": i, "category_id": 2,
                 "bbox": [60, 150, 180, 260],
                 "segmentation": [[60, 150, 240, 150, 240, 410, 60, 410]]})

coco = {"images": images, "annotations": anns,
        "categories": [{"id": 1, "name": "head"}, {"id": 2, "name": "反光衣"}]}
(ANN / "instances.json").write_text(
    json.dumps(coco, ensure_ascii=False, indent=2), encoding="utf-8")
print(f"COCO 演示数据就绪: {ROOT}  (8 图 / {len(anns)} 标注, 含分割多边形)")
```

### 2.1 `common/constants.py`（本课结束时的完整版）

```python
# apps/platform/src/od_platform/common/constants.py
```

### 2.3 `common/lineage.py`：划分契约（D3 生产、D4 核验）

这是本课最重要的模块。规则三条：

1. **划完即冻结**：把每个样本的 `(stem, split, sha256)` 逐条记进 manifest；
2. **指纹即合同**：对"配方（数据集/策略/种子/比例）+ 排序后的全部样本指纹行"做一次 sha256，得到 `contract_fingerprint`——改一个文件内容、挪一个样本到别的 split，指纹全变；`created_at` 不参与指纹；
3. **谁都可以验**：D4 拿 manifest 重算指纹对账，不需要信任 D3。

```python
# apps/platform/src/od_platform/common/lineage.py
"""划分契约:DatasetPipeline 的 lineage 记录与指纹模块。
谁负责:写 SplitManifest + 算 contract_fingerprint。
谁调用:orchestrator(产出)、materializer/yaml_writer(消费)、D4 质检(验账)。
输入:划分结果 + 每个样本的标签字节。输出:manifest.json + 契约指纹。
不变量:manifest 写完即不可变;指纹对"配方+全部样本sha256"敏感、对时间戳免疫。

为什么放在 common:D3 生产这份契约、D4 核验这份契约,两个子系统互不 import,
契约必须住在公共层 —— 它是跨子系统的"语言",不是任何一边的内部实现。
"""
from __future__ import annotations

import hashlib
import json
from dataclasses import asdict, dataclass, field
from datetime import datetime
from pathlib import Path
from typing import Dict, List, Tuple

TOOL_VERSION = "odp-transform/0.4"       # 契约版本:指纹配方变动时升号


def _sha256_bytes(b: bytes) -> str:
    return hashlib.sha256(b).hexdigest()


@dataclass(frozen=True)
class SampleLineage:
    """单样本 lineage:stem 属于哪个 split、内容 sha256 是多少。"""
    stem: str
    split: str
    sha256: str


def compute_contract_fingerprint(
    dataset: str,
    strategy: str,
    seed: int,
    ratios: Tuple[float, float, float],
    names: List[str],
    samples: List[SampleLineage],
    tool_version: str = TOOL_VERSION,
) -> str:
    """对'配方 + 排序后的样本指纹行'做规范化 sha256。

    排序是为了与集合序无关:同样的划分,谁先谁后指纹一致。
    created_at 不参与指纹 —— 指纹回答'内容是什么',不回答'何时产生'。
    """
    canonical = {
        "dataset": dataset,
        "strategy": strategy,
        "seed": seed,
        "ratios": [round(float(r), 6) for r in ratios],
        "names": list(names),
        "samples": sorted((s.stem, s.split, s.sha256) for s in samples),
        "tool_version": tool_version,
    }
    blob = json.dumps(canonical, ensure_ascii=False, sort_keys=True,
                      separators=(",", ":")).encode("utf-8")
    return _sha256_bytes(blob)


@dataclass
class SplitManifest:
    """划分契约文件:配方 + 全量样本 lineage + 指纹。写完即不可变。"""
    dataset: str
    strategy: str
    seed: int
    ratios: Tuple[float, float, float]
    names: List[str]
    samples: List[SampleLineage]
    contract_fingerprint: str = ""
    created_at: str = ""
    tool_version: str = TOOL_VERSION

    @classmethod
    def build(
        cls,
        *,
        dataset: str,
        strategy: str,
        seed: int,
        ratios: Tuple[float, float, float],
        names: List[str],
        splits: Dict[str, List[str]],
        label_bytes: Dict[str, bytes],
        created_at: str = "",
    ) -> "SplitManifest":
        """从划分结果 + 标签字节构建契约。label_bytes 以 stem 为键。"""
        samples = [
            SampleLineage(stem, split, _sha256_bytes(label_bytes[stem]))
            for split, stems in splits.items()
            for stem in stems
        ]
        samples.sort(key=lambda s: s.stem)
        m = cls(dataset=dataset, strategy=strategy, seed=seed, ratios=ratios,
                names=list(names), samples=samples,
                created_at=created_at or datetime.now().isoformat(timespec="seconds"))
        m.contract_fingerprint = compute_contract_fingerprint(
            dataset, strategy, seed, ratios, list(names), samples, m.tool_version)
        return m

    def stems_of(self, split: str) -> List[str]:
        return [s.stem for s in self.samples if s.split == split]

    def by_stem(self) -> Dict[str, SampleLineage]:
        return {s.stem: s for s in self.samples}

    # ---- 序列化 ----

    def to_json(self) -> str:
        return json.dumps(asdict(self), ensure_ascii=False, indent=2)

    def write(self, path: Path) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(self.to_json(), encoding="utf-8")

    @classmethod
    def read(cls, path: Path) -> "SplitManifest":
        d = json.loads(path.read_text(encoding="utf-8"))
        d["ratios"] = tuple(d["ratios"])
        d["samples"] = [SampleLineage(**s) for s in d["samples"]]
        return cls(**d)
```

### 2.4 `common/registry_utils.py`：注册表自动发现（公共件）

convert 和 split 的注册表都需要"导入包内所有非下划线模块、触发装饰器自注册"——同一需求第二次出现，抽成公共件。**规则：同一个抽象被手写两遍时，抽公共件；只写一遍时，不抽。**

```python
# apps/platform/src/od_platform/common/registry_utils.py
"""注册表公共件:子模块自动发现与导入。

convert/split/... 的注册表都遵循同一模式:
模块级 dict + 装饰器自注册 + 首次使用时导入所有实现模块(触发注册)。
导入副作用即注册,因此"发现哪些模块要导入"是公共逻辑,放这里。
"""
import importlib
import pkgutil
from types import ModuleType


def import_submodules(package: ModuleType) -> None:
    """导入 package 下所有非下划线开头的子模块(触发其模块级副作用)。

    下划线开头(_geometry、_common、_shared 等)视为纯工具模块,不被自动导入,
    由实现模块按需自行 import。
    """
    for info in pkgutil.iter_modules(package.__path__):
        if not info.name.startswith("_"):
            importlib.import_module(f"{package.__name__}.{info.name}")
```

```python
# apps/platform/src/od_platform/common/refs.py
"""名字 ↔ 路径 的统一解析:CLI/脚本只记名字,落盘位置由 paths.py 定。
规则:ref 含路径分隔符或是绝对路径 → 当路径用;否则当名字,补默认目录和后缀。

from typing import Optional

    MODELS_DIR, PROCESSED_DATA_DIR, RAW_DATA_DIR,

                default_suffix: Optional[str] = None) -> Path:

    return resolve_ref(ref, base_dir=RAW_DATA_DIR)

def resolve_trained_model(ref: str) -> Path:
```

### 2.6 `common/run_context.py`：审计运行目录

`runs/<subsystem>/<时间戳run_id>/` 是审计材料的家；`data/processed/` 是生产材料的家——**产物分家**：训练只读 processed，审计才翻 runs。run_id 冲突自动加 `-2`/`-3` 后缀；时间戳在构造时**只取一次**，`run_id` 和 `created_at` 同源。

```python
# apps/platform/src/od_platform/common/run_context.py
"""运行上下文:每次 odp-* 命令运行,runs/<subsystem>/<run_id>/ 下放审计材料。
规则:谁产生不可复现的运行,谁开 RunContext;产物路径由 context 发,不散落拼接。
"""
from __future__ import annotations

import re
from datetime import datetime
from pathlib import Path

from od_platform.common import paths

_SAFE = re.compile(r"^[a-z0-9_]+$")


class RunContext:
    """with RunContext('data_pipeline') as run: run.artifact_path('manifest.json')"""

    def __init__(self, subsystem: str):
        if not _SAFE.match(subsystem):
            raise ValueError(f"非法子系统名: {subsystem!r}(只允许小写字母/数字/下划线)")
        self.subsystem = subsystem
        now = datetime.now()                          # 单次获取,run_id 与 created_at 同源
        self.run_id: str = now.strftime("%Y%m%d-%H%M%S")
        self._created_at: str = now.isoformat(timespec="seconds")
        self.run_dir: Path = paths.RUNS_DIR / subsystem / self.run_id

    @property
    def created_at(self) -> str:
        return self._created_at

    def artifact_path(self, *parts: str) -> Path:
        p = self.run_dir.joinpath(*parts)
        p.parent.mkdir(parents=True, exist_ok=True)
        return p

    def __enter__(self) -> "RunContext":
        base, suffix = self.run_dir, 1
        while self.run_dir.exists():                  # 同秒冲突:run_id 加 -2/-3 后缀
            suffix += 1
            self.run_id = f"{base.name}-{suffix}"
            self.run_dir = base.with_name(self.run_id)
        self.run_dir.mkdir(parents=True, exist_ok=False)
        return self

    def __exit__(self, *exc) -> bool:
        return False                                   # 不吞异常
```

## 3. convert 子系统：格式转换（注册表 + 能力声明）

设计要点：

- **注册表**：模块级字典 + 装饰器自注册 + 首次使用懒加载自动发现。新增格式 = 在 `converters/` 下**加一个文件**，框架代码一行不动。
- **两根轴分开管**：轴 A 是"类名从哪来"（YOLO 格式不含类名，必须显式给 `--classes`，第一行就报错）；轴 B 是"格式支持什么任务"（注册时声明 `supported_tasks`，service 在门口统一拦截，各转换器只写自己会赢的分支）。
- **参数包 `ConvertOptions`**：task、classes 等横切选项打包传递，加新选项时签名不用改。
- **`classes` 三态语义**（贯穿全管线，务必记住）：`None`=不过滤（按数据自带类别）；`[...]`=白名单（**顺序即 class_id**，未列出的一律丢弃）；`[]`=全排除（主动表达，不是忘传）。
- **检查≠过滤**：转换器做"硬约束检查"（结构、路由一致性、必需字段）——发现坏数据**报错并带上文件名行号**；"可训但难看"的数据不拦，那是 D4 质检的活。

### 3.1 `convert/registry.py`

```python
# apps/platform/src/od_platform/data_pipeline/convert/registry.py
"""转换器注册表:格式名 → 转换函数 + 能力声明(supported_tasks)。

设计:模块级 dict + 装饰器自注册 + 懒加载自动发现。
新增格式 = 在 converters/ 下加一个文件,装饰器自动注册;注册表代码不动。
为什么重复注册是 ERROR:两个文件争同一个格式名,静默覆盖等于埋雷;宁可当场炸。
"""
from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path
from typing import Callable, Dict, List, Optional, Tuple

ConverterFunc = Callable[[Path, Path, "ConvertOptions"], List[str]]


@dataclass
class ConvertOptions:
    """传给所有转换器的横切选项(参数包)。加新选项时这里加字段,签名不变。"""
    task: str = "detect"                        # detect / segment
    classes: Optional[List[str]] = field(default=None)  # None=不过滤;[]=全排除;[...]=白名单


@dataclass(frozen=True)
class ConverterEntry:
    func: ConverterFunc
    supported_tasks: Tuple[str, ...]            # 注册时声明的能力

    def supports(self, task: str) -> bool:
        return task in self.supported_tasks


_CONVERTERS: Dict[str, ConverterEntry] = {}
_LAZY_INITIALIZED = False


def register_converter(format_name: str, *, supported_tasks: Tuple[str, ...]):
    """装饰器:把转换函数注册为某格式的入口,并声明它支持的任务。"""
    def deco(func: ConverterFunc) -> ConverterFunc:
        if format_name in _CONVERTERS:
            raise ValueError(
                f"转换器重复注册: {format_name!r} 已被 "
                f"{_CONVERTERS[format_name].func.__module__} 占用")
        _CONVERTERS[format_name] = ConverterEntry(func=func, supported_tasks=supported_tasks)
        return func
    return deco


def _lazy_init() -> None:
    """首次查询时,导入 converters 包内所有实现模块(触发装饰器自注册)。"""
    global _LAZY_INITIALIZED
    if _LAZY_INITIALIZED:
        return
    from od_platform.common.registry_utils import import_submodules
    from od_platform.data_pipeline.convert import converters
    import_submodules(converters)
    _LAZY_INITIALIZED = True


def get_converter(format_name: str) -> ConverterEntry:
    _lazy_init()
    try:
        return _CONVERTERS[format_name]
    except KeyError:
        raise ValueError(
            f"不支持的标注格式: {format_name!r}。可用: {sorted(_CONVERTERS)}") from None


def list_converters() -> Dict[str, ConverterEntry]:
    _lazy_init()
    return dict(_CONVERTERS)
```

### 3.3 `converters/_geometry.py`：几何换算（内部工具）

```python
# apps/platform/src/od_platform/data_pipeline/convert/converters/_geometry.py
"""几何换算:VOC/COCO 的绝对坐标 → YOLO 归一化。内部工具,不注册、不被自动发现。"""
from typing import List, Sequence, Tuple


def normalize_box(x1: float, y1: float, x2: float, y2: float,
                  W: float, H: float) -> Tuple[float, float, float, float]:
    """(左上右下, 宽高) → (cx, cy, w, h),全部归一化到 [0,1]。"""
    return ((x1 + x2) / 2 / W, (y1 + y2) / 2 / H, (x2 - x1) / W, (y2 - y1) / H)


def normalize_polygon(points: Sequence[float], W: float, H: float) -> List[float]:
    """COCO 分割多边形 [x1,y1,x2,y2,...] → 归一化,奇数位除 W、偶数位除 H。"""
    return [points[i] / W if i % 2 == 0 else points[i] / H for i in range(len(points))]
```

### 3.4 `converters/pascal_voc.py`

```python
# apps/platform/src/od_platform/data_pipeline/convert/converters/pascal_voc.py
"""Pascal VOC → YOLO。每图一个 .xml;<size> 给宽高,<bndbox> 是绝对坐标。
能力:detect(分割多边形 VOC 没有,注册时就声明了)。
"""
import xml.etree.ElementTree as ET
from pathlib import Path
from typing import List

from od_platform.common.constants import AnnotationFormat, Task
from od_platform.data_pipeline.convert.converters._geometry import normalize_box
from od_platform.data_pipeline.convert.registry import ConvertOptions, register_converter


@register_converter(AnnotationFormat.PASCAL_VOC, supported_tasks=(Task.DETECT,))
def convert_pascal_voc(input_dir: Path, output_labels_dir: Path,
                       options: ConvertOptions) -> List[str]:
    output_labels_dir.mkdir(parents=True, exist_ok=True)
    xml_files = sorted(input_dir.glob("*.xml"))
    if not xml_files:
        raise FileNotFoundError(f"在 {input_dir} 下没有找到任何 .xml 标注文件")

    # classes 三态:None=按数据自带;[...]=白名单(顺序即 class_id);[]=全排除
    if options.classes is None:
        names = sorted({o.findtext("name", "").strip()
                        for xf in xml_files
                        for o in ET.parse(xf).getroot().iter("object")})
        classes = [n for n in names if n]
    else:
        classes = list(options.classes)
    class_to_idx = {n: i for i, n in enumerate(classes)}

    for xf in xml_files:
        root = ET.parse(xf).getroot()
        size = root.find("size")
        W = float(size.findtext("width"))
        H = float(size.findtext("height"))
        lines: List[str] = []
        for obj in root.iter("object"):
            name = obj.findtext("name", "").strip()
            if name not in class_to_idx:
                continue                                # 白名单之外的类:静默丢弃
            bb = obj.find("bndbox")
            cx, cy, bw, bh = normalize_box(
                float(bb.findtext("xmin")), float(bb.findtext("ymin")),
                float(bb.findtext("xmax")), float(bb.findtext("ymax")), W, H)
            lines.append(f"{class_to_idx[name]} {cx:.6f} {cy:.6f} {bw:.6f} {bh:.6f}")
        (output_labels_dir / f"{xf.stem}.txt").write_text(
            "\n".join(lines) + ("\n" if lines else ""), encoding="utf-8")
    return classes
```

### 3.5 `converters/coco.py`

```python
# apps/platform/src/od_platform/data_pipeline/convert/converters/coco.py
"""COCO → YOLO。单 json:images/annotations/categories 三表,以 image_id 关联。
能力:detect + segment(annotations 里自带 segmentation 多边形)。
"""
import json
from collections import defaultdict
from pathlib import Path
from typing import List

from od_platform.common.constants import AnnotationFormat, Task
from od_platform.data_pipeline.convert.converters._geometry import (
    normalize_box, normalize_polygon,
)
from od_platform.data_pipeline.convert.registry import ConvertOptions, register_converter


@register_converter(AnnotationFormat.COCO, supported_tasks=(Task.DETECT, Task.SEGMENT))
def convert_coco(input_dir: Path, output_labels_dir: Path,
                 options: ConvertOptions) -> List[str]:
    output_labels_dir.mkdir(parents=True, exist_ok=True)
    json_files = sorted(input_dir.glob("*.json"))
    if not json_files:
        raise FileNotFoundError(f"在 {input_dir} 下没有找到任何 .json 标注文件")
    data = json.loads(json_files[0].read_text(encoding="utf-8"))

    cat = {c["id"]: c["name"] for c in data["categories"]}
    if options.classes is None:
        names = [cat[cid] for cid in sorted(cat)]       # 按 category_id 排序
    else:
        names = list(options.classes)
    class_to_idx = {n: i for i, n in enumerate(names)}

    img_info = {im["id"]: im for im in data["images"]}
    per_image = defaultdict(list)                       # image_id → [ann]
    for a in data["annotations"]:
        per_image[a["image_id"]].append(a)

    seg = options.task == Task.SEGMENT
    for img_id, im in img_info.items():
        W, H = float(im["width"]), float(im["height"])
        lines: List[str] = []
        for a in per_image.get(img_id, []):
            name = cat[a["category_id"]]
            if name not in class_to_idx:
                continue
            idx = class_to_idx[name]
            if seg:
                for poly in a.get("segmentation", []):
                    pts = normalize_polygon(poly, W, H)
                    lines.append(f"{idx} " + " ".join(f"{v:.6f}" for v in pts))
            else:
                x, y, w, h = a["bbox"]                  # COCO bbox: 左上 + 宽高
                cx, cy, bw, bh = normalize_box(x, y, x + w, y + h, W, H)
                lines.append(f"{idx} {cx:.6f} {cy:.6f} {bw:.6f} {bh:.6f}")
        stem = Path(im["file_name"]).stem
        (output_labels_dir / f"{stem}.txt").write_text(
            "\n".join(lines) + ("\n" if lines else ""), encoding="utf-8")
    return names
```

### 3.6 `converters/yolo.py`（直通 + 路由一致性检查）

```python
# apps/platform/src/od_platform/data_pipeline/convert/converters/yolo.py
"""YOLO → YOLO(直通 + 校验)。格式已合规,做的是:
  1. 要求显式 classes(文件里没有类名,顺序即 class_id,不能猜)
  2. 逐行检查列数与 task 路由一致(detect=5 列;segment=奇数且≥7)
检查的是"路由一致性",不是内容质量 —— 内容好坏留给 D4 质检。
"""
from pathlib import Path
from typing import List

from od_platform.common.constants import AnnotationFormat, Task
from od_platform.data_pipeline.convert.registry import ConvertOptions, register_converter


@register_converter(AnnotationFormat.YOLO, supported_tasks=(Task.DETECT, Task.SEGMENT))
def convert_yolo(input_dir: Path, output_labels_dir: Path,
                 options: ConvertOptions) -> List[str]:
    if not options.classes:
        raise ValueError(
            "yolo 格式不含类名,必须通过 options.classes 显式提供类别顺序。")
    output_labels_dir.mkdir(parents=True, exist_ok=True)
    seg = options.task == Task.SEGMENT

    for tf in sorted(input_dir.glob("*.txt")):
        out_lines: List[str] = []
        for ln, raw in enumerate(tf.read_text(encoding="utf-8").splitlines(), 1):
            raw = raw.strip()
            if not raw:
                continue
            n = len(raw.split())
            ok = (n >= 7 and n % 2 == 1) if seg else (n == 5)
            if not ok:
                raise ValueError(
                    f"{tf.name}:{ln} 列数 {n} 与 task={options.task} 不符"
                    f"(detect 需 5 列,segment 需奇数且≥7 列)")
            out_lines.append(raw)
        (output_labels_dir / tf.name).write_text(
            "\n".join(out_lines) + ("\n" if out_lines else ""), encoding="utf-8")
    return list(options.classes)
```

## 4. split 子系统：划分 + 物化

设计要点：

- **同样的注册表模式**第二次出现——自动发现逻辑复用 `common/registry_utils.import_submodules`。
- **策略即文件**：新增划分策略 = 在 `strategies/` 下加一个文件。策略注册时声明 `requires_labels`，service 在门口拦"要标签却没给"的组合。
- **物化（materialize）三原则**：一律 `copy2`（**绝不 hardlink**——链接一改源全毁）；删旧只删自己造的叶子目录，删除前 `_assert_within` 拦围栏（拒绝沙盒外、拒绝沙盒根、拒绝符号链接）；输出按数据集分桶 `data/processed/<name>/`。
- **落盘次序**：先物化，后写 yaml——yaml 是"产品合格证"，最后盖章。

### 4.1 `split/registry.py`

```python
# apps/platform/src/od_platform/data_pipeline/split/registry.py
"""划分策略注册表:策略名 → 划分函数 + 依赖声明(requires_labels)。

与 convert 注册表同一模式:模块级 dict + 装饰器自注册 + 懒加载自动发现。
新增策略 = 在 strategies/ 下加一个文件。
"""
from __future__ import annotations

import warnings
from dataclasses import dataclass, field
from typing import Callable, Dict, List, Optional

from od_platform.common.constants import (
    DEFAULT_RANDOM_STATE, DEFAULT_TRAIN_RATE, DEFAULT_VAL_RATE,
)

StrategyFunc = Callable[[List[str], "SplitOptions"], Dict[str, List[str]]]


@dataclass
class SplitOptions:
    """传给所有划分策略的横切选项(参数包)。"""
    train_rate: float = DEFAULT_TRAIN_RATE
    val_rate: float = DEFAULT_VAL_RATE
    random_state: int = DEFAULT_RANDOM_STATE
    labels_per_image: Optional[Dict[str, List[str]]] = None   # 分层策略需要
    group_per_image: Optional[Dict[str, str]] = None          # 分组策略需要(防泄漏)


@dataclass(frozen=True)
class StrategyEntry:
    func: StrategyFunc
    requires_labels: bool = False


_STRATEGIES: Dict[str, StrategyEntry] = {}
_LAZY_INITIALIZED = False


def register_strategy(name: str, *, requires_labels: bool = False):
    """装饰器:注册划分策略。同名覆盖给 warning(开发期允许迭代)。"""
    def deco(func: StrategyFunc) -> StrategyFunc:
        if name in _STRATEGIES:
            warnings.warn(f"划分策略重复注册,将被覆盖: {name!r}", stacklevel=2)
        _STRATEGIES[name] = StrategyEntry(func=func, requires_labels=requires_labels)
        return func
    return deco


def _lazy_init() -> None:
    global _LAZY_INITIALIZED
    if _LAZY_INITIALIZED:
        return
    from od_platform.common.registry_utils import import_submodules
    from od_platform.data_pipeline.split import strategies
    import_submodules(strategies)
    _LAZY_INITIALIZED = True


def get_strategy(name: str) -> StrategyEntry:
    _lazy_init()
    try:
        return _STRATEGIES[name]
    except KeyError:
        raise ValueError(
            f"未知划分策略: {name!r}。可用: {sorted(_STRATEGIES)}") from None


def list_strategies() -> Dict[str, StrategyEntry]:
    _lazy_init()
    return dict(_STRATEGIES)
```

### 4.2 `strategies/_common.py`：比例校验与切分计数

```python
# apps/platform/src/od_platform/data_pipeline/split/strategies/_common.py
"""划分策略的公共小件:比例校验、三方计数、带种子洗牌。内部工具,不注册。"""
import random
from typing import Dict, List, Sequence, Tuple

from od_platform.common.constants import RATE_EPSILON


def validate_rates(train_rate: float, val_rate: float) -> float:
    """校验比例并返回 test_rate。浮点求和,容差 RATE_EPSILON。"""
    test_rate = 1.0 - train_rate - val_rate
    if test_rate < -RATE_EPSILON:
        raise ValueError(
            f"比例不合法: train={train_rate} + val={val_rate} > 1")
    return max(0.0, test_rate)


def three_way_counts(n: int, train_rate: float, val_rate: float
                     ) -> Tuple[int, int, int]:
    """n 个样本按比例切成 (n_train, n_val, n_test);test 吃舍入余量,保证总和=n。"""
    n_train = min(n, max(0, round(n * train_rate)))
    n_val = min(n - n_train, max(0, round(n * val_rate)))
    return n_train, n_val, n - n_train - n_val


def seeded_shuffled(seq: Sequence[str], rng: random.Random) -> List[str]:
    """用调用方给的 rng 洗牌(种子由调用方掌控),返回新列表。"""
    out = list(seq)
    rng.shuffle(out)
    return out
```

```python
"""随机划分:不按类别,种子固定即可复现。requires_labels=False。"""
import random
from typing import Dict, List

from od_platform.common.constants import SplitStrategy
from od_platform.data_pipeline.split.registry import SplitOptions, register_strategy
from od_platform.data_pipeline.split.strategies._common import (
    seeded_shuffled, three_way_counts, validate_rates,
)


@register_strategy(SplitStrategy.RANDOM, requires_labels=False)
def random_split(stems: List[str], options: SplitOptions) -> Dict[str, List[str]]:
    test_rate = validate_rates(options.train_rate, options.val_rate)
    n = len(stems)
    if n == 0:
        return {"train": [], "val": [], "test": []}
    rng = random.Random(options.random_state)
    shuffled = seeded_shuffled(sorted(stems), rng)
    n_train, n_val, _ = three_way_counts(n, options.train_rate, options.val_rate)
    return {
        "train": shuffled[:n_train],
        "val": shuffled[n_train:n_train + n_val],
        "test": shuffled[n_train + n_val:],
    }
```

### 4.4 `strategies/stratified_multilabel.py`

多标签分层：贪心迭代——**最稀有标签优先**，每张图分给它最"缺"的划分（同分时按该划分已收该类样本数决胜，再同分交给 rng）。约 80 行，零第三方依赖（Sechidis 2011 的简化实现）。

```python
# apps/platform/src/od_platform/data_pipeline/split/strategies/stratified_multilabel.py
"""多标签分层划分(Sechidis 2011 简化实现):让稀有类尽量落到每个划分。

算法:按"最稀有标签"排序样本,贪心分配给当前配额缺口最大的划分;
同分时用该划分已收该类样本数决胜,再同分交给 rng(种子可控)。
零第三方依赖。requires_labels=True —— 没有 labels_per_image 直接拒跑。
"""
import random
from collections import Counter
from typing import Dict, List, Set

from od_platform.common.constants import SplitStrategy
from od_platform.data_pipeline.split.registry import SplitOptions, register_strategy
from od_platform.data_pipeline.split.strategies._common import validate_rates

_EPS = 1e-9


def _argmax_tiebreak(primary: Dict[str, float], secondary: Dict[str, float],
                     rng: random.Random) -> str:
    """按 primary 取最大;同分按 secondary 取最大;再同分 rng 随机。"""
    best_p = max(primary.values())
    cands = [k for k, v in primary.items() if abs(v - best_p) < _EPS]
    if len(cands) > 1:
        best_s = max(secondary[k] for k in cands)
        cands = [k for k in cands if abs(secondary[k] - best_s) < _EPS]
    return rng.choice(sorted(cands)) if len(cands) > 1 else cands[0]


def iterative_stratify(sample_labels: List[Set[str]], proportions: List[float],
                       random_state: int) -> List[int]:
    """返回每个样本的 fold 下标(0..len(proportions)-1)。

    贪心迭代:按"样本最稀有标签的出现次数"升序处理;每张图分给它最稀有标签
    配额缺口最大的 fold(同分按该 fold 已收该类样本数决胜,再同分 rng 随机)。
    无标签样本按 fold 总缺口填。
    """
    rng = random.Random(random_state)
    n_folds = len(proportions)
    label_count = Counter(lbl for labels in sample_labels for lbl in labels)
    n_samples = len(sample_labels)
    fold_counts = [0] * n_folds
    fold_label_counts = [Counter() for _ in range(n_folds)]
    fold_of: List[int] = [0] * n_samples

    def rarest(labels: Set[str]) -> float:
        return min((label_count[l] for l in labels), default=float("inf"))

    order = sorted(range(n_samples),
                   key=lambda i: (rarest(sample_labels[i]), i))
    for i in order:
        labels = sample_labels[i]
        if labels:
            # 样本携带的标签中最稀有者:按该标签在各 fold 的期望配额缺口分配
            # (期望配额 = 该标签总数 × fold 比例 —— 缺口是相对"标签配额"算的)
            rare = min(labels, key=lambda l: (label_count[l], str(l)))
            deficits = {str(f): label_count[rare] * proportions[f] - fold_label_counts[f][rare]
                        for f in range(n_folds)}
            secondary = {str(f): -fold_label_counts[f][rare] for f in range(n_folds)}
        else:
            # 无标签样本:按 fold 样本量总缺口填
            deficits = {str(f): n_samples * proportions[f] - fold_counts[f]
                        for f in range(n_folds)}
            secondary = {str(f): -fold_counts[f] for f in range(n_folds)}
        chosen = int(_argmax_tiebreak(deficits, secondary, rng))
        fold_of[i] = chosen
        fold_counts[chosen] += 1
        for l in labels:
            fold_label_counts[chosen][l] += 1
    return fold_of


@register_strategy(SplitStrategy.STRATIFIED_MULTILABEL, requires_labels=True)
def stratified_multilabel_split(stems: List[str],
                                options: SplitOptions) -> Dict[str, List[str]]:
    test_rate = validate_rates(options.train_rate, options.val_rate)
    if options.labels_per_image is None:
        raise ValueError("stratified_multilabel 需要 labels_per_image")
    ordered = sorted(stems)
    proportions = [options.train_rate, options.val_rate, test_rate]
    sample_labels = [set(options.labels_per_image.get(s, [])) for s in ordered]
    fold_of = iterative_stratify(sample_labels, proportions, options.random_state)

    splits: Dict[str, List[str]] = {"train": [], "val": [], "test": []}
    names = ["train", "val", "test"]
    for i, stem in enumerate(ordered):
        splits[names[fold_of[i]]].append(stem)
    return splits
```

### 4.6 `split/materializer.py`：物化（含删除围栏）

```python
# apps/platform/src/od_platform/data_pipeline/split/materializer.py
"""物化:按 manifest 把 (图,标签) 对从 raw 复制到 processed/<dataset>/{images,labels}/<split>/。

三原则:
  1. 一律 copy2,绝不 hardlink —— 链接一改源全毁
  2. 删旧只删自己造的叶子目录;删除前 _assert_within 拦围栏(沙盒外/沙盒根/符号链接一律拒绝)
  3. 以 manifest 为准:契约里有什么就落什么,不多不少
"""
from __future__ import annotations

import logging
import shutil
from dataclasses import dataclass
from pathlib import Path
from typing import Dict, List

from od_platform.common import paths
from od_platform.common.lineage import SplitManifest

logger = logging.getLogger(__name__)

_SPLITS = ("train", "val", "test")


def _assert_within(sandbox: Path, target: Path) -> None:
    """围栏:target 必须严格位于 sandbox 之内(且不等于 sandbox 本身)。"""
    sb = sandbox.resolve()
    tg = target.resolve()
    if tg == sb:
        raise ValueError(f"拒绝操作沙盒根目录本身: {tg}")
    try:
        tg.relative_to(sb)
    except ValueError:
        raise ValueError(f"拒绝操作沙盒外路径: {tg}(沙盒: {sb})") from None


def _safe_clear(leaf: Path) -> None:
    """清空叶子目录:不存在则建;是符号链接则拒绝;否则整体删除后重建。"""
    if leaf.is_symlink():
        raise ValueError(f"拒绝清空符号链接: {leaf}")
    if leaf.exists():
        shutil.rmtree(leaf)
    leaf.mkdir(parents=True, exist_ok=True)


@dataclass(frozen=True)
class SplitSourceDirs:
    """raw 侧的图源与标注源。"""
    images: Path
    labels: Path

    def resolve(self, stem: str) -> tuple[Path, Path]:
        """按 stem 找到 (图像文件, 标签文件)。同 stem 多扩展名给 warning;缺文件直接报错。"""
        imgs = sorted(self.images.glob(f"{stem}.*"))
        if not imgs:
            raise FileNotFoundError(f"图像缺失: {self.images}/{stem}.*")
        if len(imgs) > 1:
            logger.warning("同 stem 多扩展名,取第一个: %s(候选: %s)", imgs[0], imgs)
        lbl = self.labels / f"{stem}.txt"
        if not lbl.exists():
            raise FileNotFoundError(f"标签缺失: {lbl}")
        return imgs[0], lbl


@dataclass(frozen=True)
class SplitOutputDirs:
    """processed 侧的成品目录: root/<images|labels>/<split>。"""
    root: Path

    @property
    def leaves(self) -> List[Path]:
        return [self.root / kind / s for kind in ("images", "labels") for s in _SPLITS]

    @classmethod
    def for_dataset(cls, dataset: str) -> "SplitOutputDirs":
        if not dataset or "/" in dataset or "\\" in dataset or dataset.startswith("."):
            raise ValueError(f"非法数据集名: {dataset!r}")
        return cls(paths.dataset_processed_dir(dataset))

    @classmethod
    def under(cls, root: Path) -> "SplitOutputDirs":
        return cls(root)


def _copy_pair(img: Path, lbl: Path, out: SplitOutputDirs, split: str) -> None:
    shutil.copy2(img, out.root / "images" / split / img.name)
    shutil.copy2(lbl, out.root / "labels" / split / lbl.name)


def materialize(manifest: SplitManifest, source: SplitSourceDirs,
                out: SplitOutputDirs) -> Dict[str, int]:
    """按 manifest 物化。返回各 split 的样本数。"""
    for leaf in out.leaves:
        _assert_within(paths.PROCESSED_DATA_DIR, leaf)
        _safe_clear(leaf)
    counts: Dict[str, int] = {}
    for split in _SPLITS:
        stems = manifest.stems_of(split)
        for stem in stems:
            img, lbl = source.resolve(stem)
            _copy_pair(img, lbl, out, split)
        counts[split] = len(stems)
    return counts
```

## 5. `report.py`：类别平衡报告（只读）

划分之前，先让作者看见类别分布。三个原则：**只读**（不改任何文件）、**只报告不动手**（稀有类给预警日志，不替人做决定）、复用 D1 的表格绘制工具。

```python
# apps/platform/src/od_platform/data_pipeline/report.py
"""类别平衡报告:转换后、划分前,让数据集作者看见类别分布。
只读:不碰任何文件。稀有类 = 在最小 split 里的期望样本量低于阈值的类。
"""
from __future__ import annotations

import logging
from collections import Counter
from dataclasses import dataclass, field
from typing import Dict, List

from od_platform.common.constants import RARE_WARN_MIN_EXPECTED
from od_platform.common.string_utils import format_table_row, format_table_separator

logger = logging.getLogger(__name__)


@dataclass(frozen=True)
class ClassStat:
    class_id: int
    name: str
    n_images: int        # 出现在多少张图
    n_instances: int     # 共多少个实例


@dataclass(frozen=True)
class BalanceReport:
    total_images: int
    min_split_rate: float
    stats: List[ClassStat] = field(default_factory=list)
    rare: List[str] = field(default_factory=list)      # 稀有类名列表


def analyze_balance(
    per_image_classes: Dict[str, List[str]],
    names: List[str],
    min_split_rate: float,
    warn_min_expected: float = RARE_WARN_MIN_EXPECTED,
) -> BalanceReport:
    """per_image_classes: stem → 该图出现的类名列表(可重复,重复=多实例)。"""
    img_count: Counter = Counter()
    inst_count: Counter = Counter()
    for classes in per_image_classes.values():
        for c in set(classes):
            img_count[c] += 1
        for c in classes:
            inst_count[c] += 1
    stats = [ClassStat(i, n, img_count.get(n, 0), inst_count.get(n, 0))
             for i, n in enumerate(names)]
    stats.sort(key=lambda s: s.n_images)
    rare = [s.name for s in stats
            if 0 < s.n_images and s.n_images * min_split_rate < warn_min_expected]
    return BalanceReport(total_images=len(per_image_classes),
                         min_split_rate=min_split_rate, stats=stats, rare=rare)


def format_report(report: BalanceReport) -> List[str]:
    """渲染为文本行(复用 D1 的表格工具)。"""
    widths = [4, 12, 8, 8, 8, 12]
    lines = [format_table_separator(widths),
             format_table_row(["id", "name", "images", "inst", "期望", "备注"], widths),
             format_table_separator(widths)]
    for s in report.stats:
        expected = s.n_images * report.min_split_rate
        note = "稀有类!" if s.name in report.rare else ""
        lines.append(format_table_row(
            [s.class_id, s.name, s.n_images, s.n_instances,
             f"{expected:.1f}", note], widths))
    lines.append(format_table_separator(widths))
    return lines


def warn_if_rare(report: BalanceReport) -> None:
    """稀有类只预警,不拦截 —— 补不补数据是作者的决定。"""
    for name in report.rare:
        logger.warning(
            "稀有类 %r: 在最小 split 的期望样本量低于 %.1f,建议补充数据或检查划分",
            name, report.min_split_rate)
```

> `od_platform.common.string_utils` 的 `format_table_row` / `format_table_separator` 在 D1 已建好；签名是 `(columns, widths, aligns=None)`——直接复用，不要在本课重造。

## 6. `orchestrator.py`：编排 + 覆盖率闸门

编排者只做"接线"：检查原料 → 临时目录转换 → 扫描 → 平衡报告 → 划分 → 建契约 → 物化 → 写 yaml。转换先在 `tempfile` 暂存区进行，**全部成功才物化**——任何一步失败，processed 里不留半成品。

**覆盖率前置闸门**：转换前比较"标注文件数 / 图像数"。低于硬阈值（0.5）直接拒跑——覆盖率过低几乎可以断定是导出中断或路径配错，修源头比训完发现强；低于软阈值（0.9）警告放行。COCO 单 json 格式不做 stem 级检查（一个 json 覆盖全部图，数不出"标注文件数"）。

```python
编排者不实现任何一步的细节,只做接线与次序;每步的失败语义由子系统自己定。
产物分家:processed/(生产)+ runs/(审计 manifest)+ configs/(yaml 合格证)。
"""
from __future__ import annotations

import logging
import tempfile
from collections import defaultdict
from pathlib import Path
from typing import Dict, List, Optional

from od_platform.common import paths
from od_platform.common.constants import (

logger = logging.getLogger(__name__)

_SPLITS = ("train", "val", "test")


class DatasetPipeline:
    """一条命令的完整实现:odp-transform 的全部逻辑。"""

    def __init__(
        self,
        dataset: str,
        annotation_format: str,
        *,
        task: str = Task.DETECT,
        train_rate: float = DEFAULT_TRAIN_RATE,
        val_rate: float = DEFAULT_VAL_RATE,
        classes: Optional[List[str]] = None,
        random_state: int = DEFAULT_RANDOM_STATE,
        split_strategy: str = DEFAULT_SPLIT_STRATEGY,
        run: Optional[RunContext] = None,
    ):
        self.dataset = dataset
        self.annotation_format = annotation_format
        self.task = task
        self.train_rate = train_rate
        self.val_rate = val_rate
        self.classes = classes
        self.random_state = random_state
        self.split_strategy = split_strategy
        self._run_ctx = run        # 存成私有名:实例属性不能遮蔽 run() 方法
        self.raw_root = paths.raw_dataset_root(dataset)
        self.raw_images = self.raw_root / "images"
        self.raw_annotations = self.raw_root / "annotations"

    def _annotation_dir(self) -> Path:

        if self.annotation_format == AnnotationFormat.YOLO:
            return self.raw_root / "labels"
        return self.raw_annotations

    # ---- 前置检查 ----

    def _check_raw(self) -> None:
        if not self.raw_root.exists():
            raise FileNotFoundError(f"数据集不存在: {self.raw_root}")
        if not self.raw_images.exists():
            raise FileNotFoundError(f"缺少图像目录: {self.raw_images}")
        ann_dir = self._annotation_dir()

            raise FileNotFoundError(f"缺少标注目录: {ann_dir}")
        self._check_coverage()

    def _check_coverage(self) -> None:
        """覆盖率闸门:标注数/图像数 过低时直接拒跑。"""
        n_images = sum(1 for p in self.raw_images.rglob("*")
                       if p.suffix.lower() in IMAGE_EXTENSIONS)
        if n_images == 0:
            raise FileNotFoundError(f"图像目录为空: {self.raw_images}")
        if self.annotation_format == AnnotationFormat.COCO:
            logger.debug("COCO 为单 json 格式,跳过 stem 级覆盖率检查")
            return
        ann_dir = self._annotation_dir()
        n_annos = len(list(ann_dir.glob("*.*"))) if ann_dir.exists() else 0
        coverage = n_annos / n_images
        if coverage < COVERAGE_HARD_THRESHOLD:
            raise ValueError(
                f"图像-标注覆盖率 {coverage:.1%} 低于硬阈值 "
                f"{COVERAGE_HARD_THRESHOLD:.0%}(图 {n_images} / 标注 {n_annos})。"
                f"疑似标注导出中断或路径配错 —— 请修源头,不要带病训练。")
        if coverage < COVERAGE_SOFT_THRESHOLD:
            logger.warning(
                "图像-标注覆盖率 %.1f%% 低于软阈值 %.0f%%,继续但请确认是有意为之",
                coverage * 100, COVERAGE_SOFT_THRESHOLD * 100)

    # ---- 扫描:转换产物 → 内存结构 ----

    def _scan(self, staging: Path, classes: List[str]):
        image_index: Dict[str, Path] = {}
        for p in sorted(self.raw_images.rglob("*")):
            if p.suffix.lower() in IMAGE_EXTENSIONS:
                image_index[p.stem] = p
        labels_per_image: Dict[str, List[str]] = defaultdict(list)
        label_bytes: Dict[str, bytes] = {}
        for txt in sorted(staging.glob("*.txt")):
            label_bytes[txt.stem] = txt.read_bytes()
            for line in txt.read_text(encoding="utf-8").splitlines():
                line = line.strip()
                if line:
                    idx = int(line.split()[0])
                    labels_per_image[txt.stem].append(classes[idx])
        return image_index, labels_per_image, label_bytes

    # ---- 主流程 ----

    def run(self) -> Dict[str, object]:
        if self._run_ctx is not None:
            return self._execute(self._run_ctx)
        with RunContext("data_pipeline") as run:
            return self._execute(run)

    def _execute(self, run: RunContext) -> Dict[str, object]:
        self._check_raw()
        out = SplitOutputDirs.for_dataset(self.dataset)

        with tempfile.TemporaryDirectory(prefix="odp_pipe_") as staging_dir:
            staging = Path(staging_dir)
            ann_in = self._annotation_dir()
            options = ConvertOptions(task=self.task, classes=self.classes)
            classes = convert_data_to_yolo(ann_in, staging, self.annotation_format, options)

            image_index, labels_per_image, label_bytes = self._scan(staging, classes)

            report = analyze_balance(
                dict(labels_per_image), classes,
                min_split_rate=min(self.train_rate, self.val_rate,
                                   1 - self.train_rate - self.val_rate))
            for line in format_report(report):
                logger.info(line)
            warn_if_rare(report)

            stems = sorted(set(image_index) & set(label_bytes))
            splits = split_dataset(
                stems, self.train_rate, self.val_rate, self.random_state,
                strategy=self.split_strategy,
                labels_per_image={s: labels_per_image.get(s, []) for s in stems})

            manifest = SplitManifest.build(
                dataset=self.dataset, strategy=self.split_strategy,
                seed=self.random_state,
                ratios=(self.train_rate, self.val_rate,
                        round(1 - self.train_rate - self.val_rate, 6)),
                names=classes, splits=splits, label_bytes=label_bytes,
                created_at=run.created_at)
            manifest_path = run.artifact_path("manifest.json")
            manifest.write(manifest_path)
            manifest_ref = manifest_path.relative_to(paths.ROOT_DIR).as_posix()

            source = SplitSourceDirs(images=self.raw_images, labels=staging)
            counts = materialize(manifest, source, out)

            yaml_path = paths.dataset_yaml_path(self.dataset)
            write_dataset_yaml(
                yaml_path, dataset_root=out.root, classes=classes, manifest=manifest,
                dataset_name=self.dataset, source_format=self.annotation_format,
                task=self.task, manifest_ref=manifest_ref)

        logger.info("数据集 %r 完成: %s", self.dataset, counts)
        return {
            "counts": counts,
            "yaml": str(yaml_path),
            "manifest_path": str(manifest_path),
            "run_dir": str(run.run_dir),
            "contract_fingerprint": manifest.contract_fingerprint,
        }
```

## 7. CLI：`odp-transform`

`argparse` 的 `choices` 和默认值全部来自 constants——**常量一处改，CLI、注册表、转换器同时生效**。

```python
# apps/platform/src/od_platform/cli/transform_data.py
"""odp-transform:数据流水线 CLI。
退出码:0=成功;1=数据/参数错误(脏数据、覆盖率不足等);2=用法错误(argparse)。
"""
from __future__ import annotations

import argparse
import sys
from typing import List, Optional

from od_platform.common import paths
from od_platform.common.constants import (
    AnnotationFormat, DEFAULT_RANDOM_STATE, DEFAULT_SPLIT_STRATEGY,
    DEFAULT_TRAIN_RATE, DEFAULT_VAL_RATE, SplitStrategy, Task,
)
from od_platform.common.logging_utils import get_logger
from od_platform.common.run_context import RunContext
from od_platform.data_pipeline.orchestrator import DatasetPipeline

EXIT_OK = 0
EXIT_DATA_ERR = 1
EXIT_USAGE = 2

logger = get_logger(base_path=paths.LOGGING_DIR, log_type="transform")


def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(
        prog="odp-transform",
        description="把原始数据集转换为可训练的 YOLO 成品(转换+划分+物化+契约)")
    p.add_argument("--dataset", required=True, help="数据集名(data/raw/<name>)")
    p.add_argument("--format", required=True, choices=AnnotationFormat.all())
    p.add_argument("--task", default=Task.DETECT, choices=Task.all())
    p.add_argument("--train-rate", type=float, default=DEFAULT_TRAIN_RATE)
    p.add_argument("--val-rate", type=float, default=DEFAULT_VAL_RATE)
    p.add_argument("--seed", type=int, default=DEFAULT_RANDOM_STATE)
    p.add_argument("--split-strategy", default=DEFAULT_SPLIT_STRATEGY,
                   choices=SplitStrategy.all())
    p.add_argument("--classes", nargs="*", default=None,
                   help="类别白名单(顺序即 class_id);不传=按数据自带;传空=全排除")
    return p


def main(argv: Optional[List[str]] = None) -> int:
    args = build_parser().parse_args(argv)
    try:
        with RunContext("data_pipeline") as run:
            result = DatasetPipeline(
                args.dataset, args.format, task=args.task,
                train_rate=args.train_rate, val_rate=args.val_rate,
                classes=args.classes, random_state=args.seed,
                split_strategy=args.split_strategy, run=run,
            ).run()
    except (FileNotFoundError, ValueError) as e:
        logger.error("%s", e)
        return EXIT_DATA_ERR
    logger.info("yaml: %s", result["yaml"])
    logger.info("manifest: %s", result["manifest_path"])
    logger.info("fingerprint: %s", result["contract_fingerprint"])
    return EXIT_OK


if __name__ == "__main__":
    sys.exit(main())
```

```python
# apps/platform/tests/test_data_pipeline.py
"""data_pipeline 回归测试:七个测试守住本课全部关键语义。"""

from od_platform.common.constants import AnnotationFormat, SplitStrategy, Task

    """懒加载自动发现:首次查询时注册表已装满。"""
    conv = list_converters()
    assert set(conv) >= {AnnotationFormat.PASCAL_VOC, AnnotationFormat.COCO,

    assert conv[AnnotationFormat.COCO].supports(Task.SEGMENT)

    """划分守恒:一个不少、一个不重复。"""
    stems = [f"s{i:03d}" for i in range(63)]
    splits = split_dataset(stems)
    total = splits["train"] + splits["val"] + splits["test"]
    assert sorted(total) == sorted(stems)


def test_random_reproducible():
    """同种子同结果(划分可复现是契约指纹的前提)。"""
    stems = [f"s{i:03d}" for i in range(63)]
    assert split_dataset(stems, random_state=42) == split_dataset(stems, random_state=42)

    """分层策略没有 labels_per_image 直接拒跑。"""
    stems = [f"s{i}" for i in range(10)]
    with pytest.raises(ValueError, match="labels_per_image"):
        split_dataset(stems, strategy=SplitStrategy.STRATIFIED_MULTILABEL,
                      labels_per_image=None)


def test_stratified_rescues_rare_class():
    """12 张稀有类图混在 63 张里:分层划分保证每个 split 都拿到稀有类。"""
    stems = [f"c_{i:03d}" for i in range(51)] + [f"rare_{i:03d}" for i in range(12)]
    labels = {s: ["head"] for s in stems}
    for i in range(12):
        labels[f"rare_{i:03d}"] = ["head", "反光衣"]
    splits = split_dataset(stems, 0.7, 0.15, 4,
                           strategy=SplitStrategy.STRATIFIED_MULTILABEL,
                           labels_per_image=labels)
    rare_in = {sp: sum(1 for s in ss if "反光衣" in labels[s])
               for sp, ss in splits.items()}
    assert all(n >= 1 for n in rare_in.values()), rare_in


def test_report_flags_rare():
    """平衡报告抓稀有类:反光衣(12/63,最小 split 期望 1.2 < 3)被标稀有。"""
    per_image = {f"c_{i:03d}": ["head"] for i in range(51)}
    for i in range(12):

    report = analyze_balance(per_image, ["head", "反光衣"], min_split_rate=0.1)
    assert "反光衣" in report.rare
    assert "head" not in report.rare


def test_coverage_gate_rejects_broken():
    """覆盖率闸门:10 图 1 标注(10%)低于硬阈值 50%,直接拒跑。"""

    with pytest.raises(ValueError, match="覆盖率"):
        pipe.run()
```

## 9. 收尾速查

### 9.1 关键约定

| 约定 | 内容 |
|---|---|
| `classes` 三态 | `None`=按数据自带；`[...]`=白名单（顺序即 class_id）；`[]`=全排除 |
| 轴 A（类名来源） | YOLO 格式不含类名，必须显式 `--classes`，第一行就报错 |
| 轴 B（任务能力） | 注册时声明 `supported_tasks`，service 门口统一拦 |
| 检查 ≠ 过滤 | 转换器查"结构/路由一致性"，坏数据报错带文件行号；"可训但难看"归 D4 质检 |
| 注册表模式 | 模块级 dict + 装饰器自注册 + 懒加载自动发现；加格式/策略 = 加一个文件 |
| 覆盖率闸门 | <50% 拒跑（exit 1），<90% 警告；COCO 跳过 stem 级检查 |
| 契约指纹 | sha256（配方 + 排序样本行）；改内容/挪 split 指纹全变；`created_at` 不参与 |
| 产物分家 | `data/processed/`=生产（可复制可重建）；`runs/`=审计；`configs/datasets/`=yaml 合格证 |
| 落盘次序 | 先物化、后写 yaml；转换在临时目录，全部成功才物化 |
| 物化三原则 | copy2 不 hardlink；删旧只删自己的叶子；`_assert_within` 围栏 |

### 9.2 目录归置

| 东西 | 在哪 |
|---|---|
| 原始数据 | `data/raw/<name>/`（只读） |
| 成品数据 | `data/processed/<name>/{images,labels}/{train,val,test}/` |
| Ultralytics 配置 | `configs/datasets/<name>.yaml`（含 `odp_meta` 审计块） |
| 划分契约 | `runs/data_pipeline/<run_id>/manifest.json` |
| 日志 | `logs/transform/` |

### 9.3 常用排错

| 症状 | 原因与处理 |
|---|---|
| `ModuleNotFoundError: od_platform` | 没装 editable：`pip install -e ./apps/platform` |
| Windows 下日志/文件中文乱码 | 设 `PYTHONUTF8=1`（或确认各文件都显式 `encoding="utf-8"`） |
| `不支持的标注格式` | 检查 `--format` 拼写；新格式需在 `converters/` 下加文件注册 |
| `列数 N 与 task 不符` | YOLO 源数据列数与 `--task` 不匹配（detect=5 列，segment=奇数且≥7） |
| 覆盖率拒跑 | 去数 `data/raw/<name>/annotations/` 的文件数——标注导出中断就重导 |

```diff
+"""新增：D3/D4 共用进度事件；CLI 和 Web 使用同一份真实计数。"""
+
+from __future__ import annotations
+
+import sys
+import time
+from collections.abc import Callable, Iterable, Iterator
+from contextlib import contextmanager
+from contextvars import ContextVar
+from typing import TypeVar
+
+ProgressCallback = Callable[[dict], None]
+_callback: ContextVar[ProgressCallback | None] = ContextVar("odp_progress", default=None)
+T = TypeVar("T")
+
+
+@contextmanager
+def progress_scope(callback: ProgressCallback | None = None):
+    """每次运行隔离回调，嵌套调用保留外层回调，异常时也恢复上下文。"""
+    token = _callback.set(callback or _callback.get())
+    try:
+        yield
+    finally:
+        _callback.reset(token)
+
+
+def emit_progress(stage: str, completed: int = 0, total: int = 0) -> None:
+    callback = _callback.get()
+    if callback is not None:
+        callback(
+            {
+                "stage": stage,
+                "completed": completed,
+                "total": total,
+                "percent": round(completed / total * 100, 1) if total else 0.0,
+            }
+        )
+
+
+def track(items: Iterable[T], stage: str, total: int | None = None) -> Iterator[T]:
+    """完成一次工作后再递增；限制回调频率，避免大数据集被 UI 更新拖慢。"""
+    if total is None:
+        total = len(items) if hasattr(items, "__len__") else 0
+    emit_progress(stage, 0, total)
+    last = time.monotonic()
+    completed = 0
+    for item in items:
+        yield item
+        completed += 1
+        now = time.monotonic()
+        if now - last >= 0.1:
+            emit_progress(stage, completed, total)
+            last = now
+    emit_progress(stage, completed, total)
+
+
+class ConsoleProgress:
+    """新增：无第三方依赖的终端进度条；重定向输出时使用逐行日志。"""
+
+    def __init__(self, stream=None):
+        self.stream = stream or sys.stderr
+        self.stage = None
+
+    def __call__(self, event: dict) -> None:
+        stage, completed, total = event["stage"], event["completed"], event["total"]
+        tty = self.stream.isatty()
+        if not tty and stage == self.stage and total and completed < total:
+            return
+        if tty and self.stage is not None and stage != self.stage:
+            self.stream.write("\n")
+        self.stage = stage
+        filled = min(20, int(event["percent"] / 5))
+        bar = "#" * filled + "-" * (20 - filled)
+        count = f"{completed}/{total} {event['percent']:.1f}%" if total else "处理中"
+        prefix = "\r" if tty else ""
+        self.stream.write(
+            f"{prefix}[{bar}] {stage}: {count}" + ("\n" if not tty or stage == "complete" else "")
+        )
+        self.stream.flush()
```

+## 质检与历史
+
+- 图片：先校验文件容器，再实际解码像素，空图、损坏图及截断图片均报 ERROR。
+- 标签：复用原有结构、`0 <= class_id < nc`、坐标归一化与边界检查；新增 NaN/Infinity、非正框尺寸、编码/读取错误处理。bbox 边界仍按原有容差及比例分级。
+- 契约：逐样本 SHA256 独立重算的语义保持一致，加入进度反馈。
+- 报告：保存到 `runs/data_validation/<run_id>/report.json`、`results.csv`，JSON 采用原子替换；运行 ID 包含微秒和随机后缀，显式重复 ID 会被拒绝。
+- 历史：只比较同一 YAML 路径、同一任务的上一次报告。首次运行建立基线。图片、标签格式、框越界、契约按文件/行/问题类型精确比较，其他原有检查按检查项跟踪。完整问题保存在 JSON，页面每类预览最多 100 条、历史记录最多 50 次，总数不受预览限制。跳过、崩溃和无法读取的文件不冒充已修复；旧报告粒度不同时重新建立该检查的基线。
